# Temperature Alarm System

## Overview

This Arduino project monitors temperature using a temperature sensor.

When the measured temperature exceeds a predefined threshold, the system activates a red LED and a buzzer to alert the user.

---

## Features

- Monitor temperature.
- Detect high temperature.
- Activate LED and buzzer alarm.
- Real-time sensor monitoring.

---

## Concepts Practiced

- Analog sensor reading
- Conditional statements
- Sensor calibration
- LED control
- Buzzer control
- Arduino programming

---

## What I Learned

Through this project, I learned how to:

- Read analog values from a sensor.
- Compare sensor readings with predefined thresholds.
- Trigger different outputs based on sensor values.
- Build a simple monitoring and alarm system.
